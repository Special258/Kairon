# 🌟 About Kairon

> **See the signal. Keep the relationship.**

**Kairon** is a customer relationship intelligence and retention decision platform designed to help customer success, account management, and revenue teams identify **churn risk early**, understand the **reasons behind the risk**, estimate the **financial exposure**, and determine a practical **next action**.

Instead of functioning as another passive analytics dashboard, Kairon acts as a decision layer between customer data and the next conversation a team needs to have.

### 🎯 The Core Idea

Customer risk rarely comes from a single data point.

It can emerge from a combination of:

📉 Declining product usage
🎯 Low feature adoption
🎫 Increasing support activity
💳 Late payment behavior
📆 Contract and tenure signals
❤️ Customer sentiment / NPS
💰 Revenue exposure

Kairon brings these signals together into a single workflow:

```text
        CUSTOMER SIGNALS
              │
              ▼
     ┌───────────────────┐
     │   ML PREDICTION    │
     └─────────┬─────────┘
               │
               ▼
       📊 CHURN PROBABILITY
               │
               ▼
       🔍 RISK EXPLANATION
               │
               ▼
       💰 REVENUE EXPOSURE
               │
               ▼
       🎯 RETENTION ACTION
               │
               ▼
       🤝 TEAM REVIEW
```

# 💡 Why Kairon?

Traditional tools often answer:

> ❓ What happened?

> ❓ What data do we have?

> ❓ What does the account record contain?

> ❓ What does the model predict?

Kairon is designed around a more actionable question:

> ### 🎯 “What should our team understand and do next to protect this relationship?”

# ✨ Key Features

| 🚀 Feature                      | 📝 Description                                                                                |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| 🎯 **Churn Prediction**         | Estimates the probability of customer churn using multiple customer signals.                  |
| 🚦 **Risk Classification**      | Converts prediction output into Low, Moderate, High, and Critical risk tiers.                 |
| 🔍 **Explainable Risk Drivers** | Highlights the strongest factors influencing the prediction.                                  |
| 💰 **Revenue at Risk**          | Translates churn probability into financial exposure.                                         |
| 🧮 **Customer Lifetime Value**  | Provides estimated customer value alongside risk.                                             |
| 🎯 **Retention Playbook**       | Converts risk insights into practical retention actions.                                      |
| 📊 **Cohort Scoring**           | Allows multiple customer accounts to be scored together through CSV uploads.                  |
| 🔎 **Account Analysis**         | Provides detailed account-level risk analysis.                                                |
| 🧪 **What-if Simulation**       | Compares baseline and simulated customer conditions.                                          |
| 🤝 **Team Reviews**             | Provides a shared workflow for account context, notes, risk explanation, and retention plans. |
| 🔐 **Authentication**           | Supabase-backed email/password and Google OAuth session state.                                |
| 📈 **Model Metrics**            | Provides model evaluation metrics and feature importance.                                     |
| 🔄 **Model Retraining**         | Supports model retraining and re-benchmarking through the API.                                |

# 🤝 Human-Centered Decision Making

Kairon is designed around an important principle:

> **Prediction should support human judgment — not replace it.**

The model identifies patterns.

👨‍💼 Customer teams understand relationships.

🧠 Account managers understand context.

🤝 Teams make the final decision.

This is why Kairon combines:

**Prediction + Explainability + Financial Context + Human Review**

---

# 🎯 Product Philosophy

### 🔍 Every Score Needs a Reason

A prediction without explanation can create distrust.

Kairon therefore surfaces the major drivers behind risk.

### 🎯 Every Reason Should Lead to an Action

The system goes beyond:

> ❌ “Risk is high.”

and moves toward:

> ✅ “Here is why the risk is high and what the team can consider doing next.”

### 💰 Financial Context Matters

Revenue exposure and estimated customer lifetime value provide additional context for prioritization.

### 🤝 Humans Stay in the Loop

The platform is designed to support customer teams rather than make customer decisions without human oversight.

```bash

```

## 2️⃣ Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

The Vite development server will provide the local frontend URL.

---

## 3️⃣ Backend Setup

Open another terminal:

```bash
cd backend
```

Create a virtual environment:

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start FastAPI:

```bash
uvicorn main:app --reload
```

# 🔒 Responsible AI

Kairon is designed with responsible decision support in mind.

### Principles

🧠 **Human Oversight**
Model predictions should support human decision-making.

🔍 **Explainability**
Risk predictions should provide understandable drivers.

⚖️ **Model Monitoring**
Future production versions should monitor model behavior across customer segments.

📝 **Reason Capture**
Human overrides and contextual decisions should be recorded.

🚫 **No Automated Punitive Decisions**
The churn score should not be the sole basis for punitive or exclusionary treatment of customers.
